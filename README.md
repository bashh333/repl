# Эмулятор оболочки ОС (Shell Emulator)

Учебный проект по конфигурационному управлению. Эмулятор командной строки с поддержкой виртуальной файловой системы 
(VFS) и выполнения стартовых скриптов.

---

## Реализованная функциональность

### Этап 1: Интерактивный цикл REPL
* Реализован базовый цикл чтения и выполнения команд (REPL).
* Поддержка завершения сессии командой `exit`, а также по сочетаниям клавиш `Ctrl+C` (`KeyboardInterrupt`) и `Ctrl+D`
* (`EOFError`).
* Базовые заглушки команд: `ls`, `cd`, `echo`.
* Раскрытие переменных окружения (например, `$USER`).

### Этап 2: Параметры командной строки и пакетный режим
* Обработка аргументов запуска через `sys.argv` (путь к образу VFS и путь к стартовому скрипту).
* Автоматическое выполнение команд из файла скрипта (`start.txt`):
  * Вывод выполняемых команд в стандартный поток вывода в формате `[vfs_name]$ команда`.
  * Пропуск пустых строк и комментариев (начинающихся с `#`).
  * Немедленная остановка с кодом ошибки при сбое любой команды скрипта.
* Использование именованных констант вместо магических чисел.
* Скрипт автоматизации запуска `run.sh` с пробросом аргументов через `"$@"`.
