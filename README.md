# Эмулятор оболочки ОС (Вариант №22)

Учебный проект по дисциплине «Конфигурационное управление» (РТУ МИРЭА).
Эмулятор командной строки UNIX-подобной ОС с поддержкой виртуальной файловой
системы (VFS) на основе CSV-образов и режимом пакетного выполнения скриптов.

---

## 1. Общее описание

Программа представляет собой консольный интерпретатор команд (CLI).
Файловая система изолирована в оперативной памяти и загружается из CSV-файла.
Все операции над файлами и директориями (`touch`, `mv`, `cd`, `ls`) происходят
в памяти без модификации исходного физического файла на диске.

---

## 2. Описание команд и параметров запуска

### Параметры командной строки
- Аргумент 1: путь к файлу виртуальной файловой системы (`.csv`).
  По умолчанию используется `vfs.csv`.
- Аргумент 2: путь к стартовому скрипту эмулятора (например, `start.txt`).

### Поддерживаемые команды эмулятора
- `ls [каталог]` — вывод содержимого директории.
- `cd [каталог]` — переход в указанную директорию (`..` — на уровень выше).
- `echo [аргументы]` — вывод переданной строки на экран.
- `whoami` — вывод имени текущего пользователя ОС.
- `clear` — очистка экрана терминала.
- `touch <файл>` — создание пустого файла в виртуальной файловой системе.
- `mv <источник> <назначение>` — переименование или перемещение объекта VFS.
- `vfs-load <путь>` — загрузка нового CSV-образа файловой системы в память.
- `help` — вывод справки по доступным командам.
- `exit` — завершение работы программы.
